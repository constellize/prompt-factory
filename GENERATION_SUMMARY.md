## Meta-Prompt: Generate Prompts for Prompt Factory

### Overview
Created a comprehensive meta-prompt that helps generate new prompts following all factory guidelines automatically.

**Location:** `prompts/meta/generate-prompt-prompt.txt`

### What It Does
Takes high-level specifications and generates complete, well-structured prompts that follow:
- XML tag structure (`<task>`, `<thinking>`, `<output-format>`, `<warning>`)
- Strategic CAPITALIZATION guidelines (<2% of words)
- Token efficiency principles (minimal viable context)
- Category-appropriate output formats
- Thinking frameworks and success criteria
- Common mistake warnings

### Files Created
- `generate-prompt-prompt.txt` (9.7 KB) - Main meta-prompt
- `generate-prompt-metadata.json` (442 B) - Metadata
- `generate-prompt-preview-callout.md` (193 B) - Preview callout
- `generate-prompt-book-markdown.md` (10 KB) - Book integration format
- `README.md` (2.5 KB) - Meta folder documentation

### Inputs Required
- `purpose`: What the prompt should accomplish
- `chapter`: Book chapter it belongs to
- `category`: Architecture | Analysis | Design | Review | Implementation | Maintenance
- `use_case`: When to use this prompt
- `context`: (optional) Additional background
- `tags`: Comma-separated categorization tags

### Category Templates Encoded
1. **Architecture** → Design Approach, Trade-offs, Implementation Guidance
2. **Analysis** → Current State, Analysis, Recommendations
3. **Design** → Requirements, Design Proposal, Implementation Plan
4. **Review** → Assessment, Issues Found, Recommendations
5. **Implementation** → Implementation Approach, Code Structure, Testing Strategy
6. **Maintenance** → Current State, Maintenance Tasks, Best Practices

### Benefits
- **Consistency:** All prompts follow the same high standards
- **Speed:** Generate in minutes vs hours of manual writing
- **Quality:** Enforces best practices automatically
- **Onboarding:** New contributors can create quality prompts immediately
- **Maintenance:** Update the meta-prompt to improve all future generations
